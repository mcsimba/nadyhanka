# #надиханка — сайт

Каталог надиханок з каналу [«Нотатки креадира»](https://t.me/creanotes): 10 питань людям, що надихають.

Статичний сайт без сервера і бази: `index.html` + `assets/` + `data/`. Відкривається навіть подвійним кліком по `index.html`.

## Сторінки

- **Гості** (`#guests`) — каталог з обкладинками, пошук за іменем або сферою.
- **Гість** (`#g-maksym-lesniak`) — вступ, 10 відповідей, зміст збоку, під кожною відповіддю «Як відповіли інші».
- **Питання** (`#questions`, `#q-1` … `#q-10`) — відповіді всіх гостей на одне питання.
- **Про рубрику** (`#about`).

## Як додати нову надиханку

1. Опублікуйте її на telegra.ph як завжди (обкладинка першою картинкою, питання з номерами «1.», «2.» …).
2. У терміналі в цій папці:

```bash
python3 tools/import.py add "https://telegra.ph/nadihanka-vіd-..." --name "Ім'я Прізвище" --role "Коротко, хто це"
```

Якщо надиханка вийшла прямо в каналі, дайте посилання на пост (або на кілька постів поспіль, якщо вона розбита на частини):

```bash
python3 tools/import.py add https://t.me/creanotes/1655 https://t.me/creanotes/1656 --name "Ім'я Прізвище" --role "Коротко, хто це"
```

Скрипт сам завантажить текст і обкладинку, знайде 10 відповідей і оновить `data/nadyhanky.js`.
Якщо вступу немає на telegra.ph (він лише в пості каналу) — додайте `--intro "текст"` або впишіть поле `intro` у `data/sources.json`.

Щоб перечитати всі надиханки заново (наприклад, після правок на telegra.ph):

```bash
python3 tools/import.py
```

Щоб замінити обкладинку, покладіть картинку в `assets/covers/custom/` і впишіть гостю в `data/sources.json` поле `"cover": "assets/covers/custom/файл.jpg"`.

Ім'я, опис і вступ гостя можна правити в `data/sources.json`, після чого запустити `python3 tools/import.py`.

## Прев'ю для Telegram і соцмереж

У кожного гостя є «справжня» адреса `https://www.creanotes.com.ua/g/<slug>/` — саме вона в адресному рядку на сторінці гостя, і саме її варто шерити.
За цією адресою лежить маленька сторінка `g/<slug>/index.html` з обкладинкою, ім'ям і описом гостя (їх бачать Telegram, Facebook, LinkedIn), яка одразу відкриває сайт.
Посилання на конкретну відповідь: `…/g/<slug>/#q3`.

Ці сторінки генерує `tools/import.py` автоматично разом із `data/nadyhanky.js`. Перегенерувати лише їх (без завантаження з telegra.ph):

```bash
python3 tools/import.py pages
```

Telegram кешує прев'ю. Якщо посилання вже шерили до змін — оновити картку можна через бота @WebpageBot.

## Як опублікувати

Сайт живе на Vercel і оновлюється сам після кожного `git push` у GitHub.

Після додавання надиханки:

```bash
git add -A && git commit -m "Нова надиханка" && git push
```

На сайт не потрапляють `mockups/`, `tools/`, `.claude/` і цей README (див. `.vercelignore`).
